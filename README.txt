TWISTED CITRUS WEBSITE — QUICK START

FILES
- index.html: website content and all links
- styles.css: colors, spacing and mobile layout
- script.js: opens menu graphics in full-screen popups
- assets/: logos and menu graphics

PREVIEW ON YOUR COMPUTER
1. Unzip the folder.
2. Double-click index.html.
3. It will open in your browser.

PUBLISH FREE WITH GITHUB PAGES
1. Create a free GitHub account.
2. Create a new public repository named twisted-citrus.
3. Upload every file and the assets folder.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main and /root, then Save.
7. GitHub will provide your free website address.

EASY UPDATES
- Change a link: open index.html in any text editor and replace the URL.
- Change a menu image: replace the matching file in assets while keeping the same filename.
- Change colors: open styles.css and edit the gradient for that button.
